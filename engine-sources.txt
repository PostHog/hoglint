# The files that define hoglint, as glob patterns relative to tools/hoglint, in three sections.
# Each section makes one id, and each one adds files to the section above it:
#   [facts]   the extractor and the link code that writes and reads a fact cache entry. Its id
#             keys the per-blob fact cache, so other link or Python changes never re-extract.
#             A new link file is in [facts] until it is excluded here.
#   [native]  [facts] plus the link and the binding: the whole Rust side. The loaded extractor
#             and native module must report this id, or the run stops with "rebuild" (exit 2).
#   [engine]  [native] plus the Python engine and presets, and the protocol line. Its id keys run
#             summaries (hoglint/ledger/envelope.py) and is what CI publishes them under.
#
# A section's files are the section above's files, plus every file that matches one of its own
# patterns and none of its own `!` patterns. `**` matches any number of directories, none
# included; `*` matches any characters within one path segment. Paths use `/`. Directories
# named `target` or starting with `.` are never searched.
#
# An id is the first 8 bytes, in hex, of the sha256 of: for [engine] only, the protocol line
# (`protocol 3`) and a NUL byte; then, for each of the section's files sorted by path (bytewise),
# the path, NUL, the file's bytes, NUL. build.rs and envelope.py both compute them from this file.
# The protocol is the run summary format version (PROTOCOL in hoglint/ledger/envelope.py).
